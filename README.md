# Dylan's Academy 2.0 — Horizon

A minimalist, charcoal-and-white, offline-friendly study app.

## Publish
Upload the contents of this folder to the root of your existing GitHub Pages repository, replacing the matching files.

## Existing notes
On first launch, the app copies notes from `dylans-academy-notes-v1` into `dylansAcademyV2` without deleting the original key. Keep the old app data intact until you have confirmed your notes appear in the new Notebook.

## Important
Data is stored locally in the browser on this device. Export/backup functionality is not included in this starter build. Grade bands shown are provisional examples, not official KNEC grading rules.
