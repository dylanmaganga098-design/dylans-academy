# Horizon — Version 2.1 Savannah Preview

This update adds Savannah's first offline-ready foundation:
- A dedicated Savannah section in the app.
- A learner profile for class/level and learning goals.
- A growth profile based on recorded grades and completed topics.
- An offline question queue saved on the device.

Important: this is the interface and offline foundation only. Savannah is **not yet connected to a live AI model**. Saved questions remain on this device until a secure online AI backend is added. No API key is included in this public app.

## Update
Upload all six files to the root of the existing `dylans-academy` GitHub repository and commit them to `main`. Keep the existing repository and GitHub Pages settings. The app is now branded Horizon and retains its existing `dylansAcademyV2` data and adds Savannah data to the same local storage record.
